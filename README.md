# ROPE DUEL 3D

A from-scratch Three.js 0.186 3D cat duel over BTC/USDT order flow.

Live: https://shojaee76-cmyk.github.io/rope-duel-3d/

Two articulated cats, SULTAN BID and DON ASK, fight on a suspended rope. Binance, Bybit, and Gate feed the order flow; the page falls back to an honest SIM TAPE when no exchange is reachable.
